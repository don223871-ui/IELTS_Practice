## 2. CORE PROJECT IDEA

This is **not simply an IELTS question page**.

It is an integrated learning worksheet in which the student moves from:

**SOURCE → DIAGRAM → LANGUAGE → STRUCTURE → SENTENCE → PARAGRAPH → FULL TASK → SELF-CHECK**

The vocabulary, collocations and grammar are connected directly to the process shown in the Sulphur Cycle and then transferred into the final IELTS Task 1 writing.

Working concept:

> **IELTS PROCESS WRITING LAB**  
> *From Diagram → Language → Structure → Writing → Self-Assessment*

---

## 3. LEARNING ARCHITECTURE

### Main progression

1. Understand the task and source.
2. Read and map the process diagram.
3. Build the language of the process.
4. Practise structures suitable for process writing.
5. Rewrite individual stages in IELTS style.
6. Build and organise the overview.
7. Write the complete Task 1 response.
8. Compare with the sample answer.
9. Self-assess using IELTS criteria.
10. Reflect on transferable language and structures.

### Central learning principle

The student should **learn the language needed for the writing while working through the actual process**, rather than studying disconnected vocabulary lists and grammar exercises.

## 9. IELTS TASK

### Task type

**Writing Task 1 — Process Diagram**

### Topic

**The natural and human-related processes involved in the sulphur cycle**

### Task focus

The response should summarise the main stages from sulphur release through atmospheric transformation, deposition, uptake, decomposition and longer-term storage, selecting the major features and organising them clearly.

### Writing target

**At least 150 words.**

### Model-answer standard

The model response is designed around a strong **Band 8–8.5** direction, with:

- clear paraphrased introduction
- effective overview
- logical process grouping
- accurate passive structures
- sequencing
- cause/result relationships
- precise process vocabulary
- controlled academic style
- no unnecessary unsupported scientific claims

---

## 10. SELF-CHECK FRAMEWORK

The final writing should be evaluated through the four IELTS criteria:

1. **Task Achievement**
2. **Coherence & Cohesion**
3. **Lexical Resource**
4. **Grammatical Range & Accuracy**

The student should also identify:

- useful vocabulary worth retaining
- reusable process structures
- errors to correct
- language transferable to future Process Tasks
